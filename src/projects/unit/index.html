The build process

We release OCI images for all of our apps, as well as helm charts¹. This is done automatically by an GitHub Action which first tests all our images, and if they pass we push their OCI image to GitHub's container registry. We also support doing CI locally via {% set local_development_example = open_relative("examples/local-development.sh").read() %}

A small scale example similar to how unit is set up can be found under my Bazeling repo.
