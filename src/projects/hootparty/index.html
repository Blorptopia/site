What is Hootparty

Hootparty was our custom platform for running quizzes live, similar to what Kahoot provides. Hootparty supports a few additional quality of life features compared to Kahoot

  • An quiz admin panel seperate from the host UI for additional details and remote administration
  • Reconnecting after losing connection to the server

In addition to the extra quality of life features, Hootparty supports a few more question types

  • A map of the world where you need to click the objective
  • Blurring the alternatives, inspired by EPT's ept-hoot
  • Question that mimicks nano-learning's UI and requires you to read through a bunch of nonsense text
  • Highlight all the words in the text fitting the objective (Highlight all the buzzwords)
  • How tall is this thing/person
  • Switcharoo - where the alternatives swap around when clicked
  • Try to answer as similar as the others answering the question
