Curse is a silly little potion brewing game I made together with a few friends, where you buy ingredients with various twists like "needs to be heated between 50°c and 60°c" or "can only be rotated clockwise".

Overview

Curse was made without a game engine - it instead uses Lit (the web framework) to manage state and absolutely positioned img tags to render the content.

This also applies to the entities in the scene (aka any physics object)

While this worked, this was not the smartest idea considering we had limited time due the rules of the gamejam. This ended with the gameplay being very shallow and unbalanced.

The flask

At the center of curse is the flask. This is where you do all the brewing, and where the ingredients twist's are active.

{{ visualization_error() }}

But lets take a step back first to see how this is rendered. The flask consists of 1 "layer" per instance of an ingredient inside the flask. Each layer is built up of "rasterized" points on a sine wave, with a line between each point. If the "wave resolution" is too low you can see the individual segments.

In the production instance of Curse, this is 20 points.

{{ visualization_error() }}

The wave is animated by changing the offset to increase with 2π every 2 seconds, but also by adding a small variation to the height of the point to emulate the liquid boiling.

Now that we have the liquids, we mask it out to draw just the liquid inside the flask, and render a flask on top of it. In the production instance of Curse, the mask is bigger than the flask itself. We solve this in production by rendering yet another flask image, just a tad bit bigger to hide the issue.

This is what we have so far:

{{ visualization_error() }}

and this might look a bit different than the flask you see in game. This is due to the production instance having a second slightly darker and reversed "backing" wave behind the topmost layer to emulate depth.

{{ visualization_error() }}

Now, the instances aren't usually just the same color, they change based on the state of the instance. Each instance layer starts out with the ingredient's base color, and is mixed with transparency for how raw the ingredient is, is desaturated for how unmixed it is and is mixed with brown for how "wrongly" cooked it is (burnt / too low temp)

The code and gameplay also mentions that it will turn purple if poisoned by you not following the instructions (e.g. spin direction), however no effect that emitted poison was implemented in the production instance of the game, however the placebo itself was powerful enough for the players to enjoy the feature.
